# 🏢 밍끼 오피스 (프로토타입)

민지 님 전용 모바일·웹 겸용 오피스 웹앱입니다. 순수 HTML / CSS / JavaScript만으로 만들었기 때문에
서버나 빌드 과정 없이 어떤 정적 호스팅에도 그대로 올릴 수 있습니다.

## 파일 구성

```
mingki-office/
├── index.html            화면 구조 (헤더 · 4개 탭 · 방 상세 시트)
├── style.css             디자인 (크림/파스텔, 따뜻한 우드 스튜디오 감성, 반응형)
├── app.js                탭 전환 · 캐릭터 산책 · 방 상세 · 메모장 저장
├── manifest.json         홈 화면 추가용(PWA) 설정 — 앱 이름·아이콘·테마색
└── assets/
    ├── office-map.png    오피스 평면도 (원본 PNG)
    ├── office-map.webp   같은 이미지의 가벼운 버전(약 1/10 용량, 자동 우선 사용)
    ├── icon-180.png      아이폰 홈 화면 아이콘
    ├── icon-192.png / icon-512.png / icon-1024.png
    └── icon-maskable-512.png
```

## 기능

| 탭 | 내용 |
|---|---|
| 🗺️ 오피스 맵 | 평면도 위 4개 방 라벨(누르면 상세) · 망두(하늘색 ㅁ)와 밍끼(골프 프로)가 방 사이를 걸어 다니며 말풍선 · 캐릭터를 누르면 한마디 변경 · 지금 누가 어느 방에 있는지 표시 |
| 📋 프로젝트 보드 | 실제 진행 중인 6개 프로젝트 현황 (발행 완료 / 임시저장 / 심사 대기 / 결정 대기) · 오사카 여행 D-day 자동 계산 |
| 🔗 바로가기 | 골프 블로그 · 일상 블로그 · 네이버 클립 · 유튜브 · 인스타그램 · 카카오 오픈채팅 (새 탭) |
| 📝 메모장 | 퀵 메모 + 오늘의 체크리스트 — 브라우저 `localStorage`에 자동 저장 |

## 로컬에서 열기

- 파일을 그냥 더블클릭해도 대부분 동작합니다. (Safari/Chrome에서 `index.html` 열기)
- 폰에서 보려면 폴더째로 열 수 없기 때문에, 아래처럼 정적 호스팅에 올리는 방법이 가장 간단합니다.

## 배포 방법 (무료)

1. **GitHub Pages**
   - 새 저장소(예: `mingki-office`)를 만들고 이 폴더의 파일들을 그대로 올립니다.
   - Settings → Pages → Source 를 `Deploy from a branch` → `main` / `/ (root)` 로 저장.
   - 1~2분 뒤 `https://<아이디>.github.io/mingki-office/` 주소로 열립니다.
2. **Vercel / Netlify**
   - 로그인 후 "Import project"에서 이 폴더를 끌어다 놓거나 저장소를 연결하면 빌드 설정 없이 바로 배포됩니다.

> 아이폰 사파리에서 주소를 연 뒤 **공유 → 홈 화면에 추가**를 누르면 앱처럼 전체 화면으로 열리고,
> 아이콘과 이름은 `manifest.json` + `apple-touch-icon` 설정을 따라갑니다.

## 메모 저장에 대해

- 메모와 체크리스트는 **그 브라우저에만** 저장됩니다(서버 전송 없음). 기기를 바꾸거나 브라우저 데이터를 지우면 사라집니다.
- 사파리 시크릿 모드에서는 저장이 되지 않을 수 있습니다.
